Tutorials
=========

As a practical starting point for using SAFIRE, we provide an extensive set of tutorials. The tutorials come in three tracks, each tailored to a different background and systems of interest. Each track covers enough to teach a user unfamiliar with :ref:`afqmc` and SAFIRE to perform their first own simulations and interpret their results. The tutorials further make heavy use of the :ref:`safiretools` companion package for handling input and output files.

For more advanced use-cases, we also provide a wide range of :ref:`user_examples` that can serve -- along with the tutorials -- as a base for further customization. The :ref:`user_manual` and :ref:`safiretools` documentation act like a complementary references that cover the details of available configuration options, file formats and python tools. 

To get started, choose one of the tracks and start at the top.
